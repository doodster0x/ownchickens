# OwnChickens.com

The beginner's guide to backyard laying hens, written for everyday US families. It's plain-language, practical and Midwest-friendly.

Static HTML, CSS and vanilla JavaScript, hosted on GitHub Pages. There is no build step to deploy: the HTML files in the repo are the site.

## Configuration (`site-config.js`)

Everything is blank by default, and the site works normally while it is blank.

### Email signup (MailerLite)

Email is handled by MailerLite (account `2722517`, embedded form `8qmT6L`). It is configured in `signup` in `site-config.js`:

- `script.js` loads MailerLite's universal script (`https://assets.mailerlite.com/js/universal.js`, `ml('account', '2722517')`) and, on every page with a signup box, inserts `<div class="ml-embedded" data-form="8qmT6L"></div>` in place of the built-in form.
- **Fallback:** the built-in form (generated by `tools/layout.py`) is hidden while MailerLite loads. If the script is blocked or the embed has not rendered after `fallbackAfterSeconds`, it reappears with a message and a link to the printable checklist. It never sends data. Without JavaScript it also just links to the checklist.
- Set `signup.provider` to `""` to return to the "coming soon" placeholder, or leave it empty and set `signup.actionUrl` / `emailFieldName` to use a plain HTML form from another provider (Buttondown, Kit).

**You must set up the welcome email in MailerLite:** the site cannot send it. In MailerLite, create an Automation that triggers when a subscriber joins the group or form `8qmT6L`, with an email that links to the checklist: **https://ownchickens.com/checklist.html**. A PDF version is optional. Also enable double opt-in or confirmation as you prefer; `privacy.html` already names MailerLite.

### Amazon Associates (TODO: add your tag once approved)

Every Amazon link uses `data-amazon-search="..."`. When `affiliates.amazonTag` is set (for example `"ownchickens-20"`), `script.js` adds `tag=` to every Amazon link site-wide and marks it `rel="sponsored noopener"`. While it is empty, the links are plain Amazon searches. Disclosures are already on `supplies.html`, every `reviews/` page and `privacy.html#affiliate-disclosure`. Specific product picks should only be added after hands-on use. Look for the `AFFILIATE-PLACEHOLDER` comments in `reviews/*.html`.

### Analytics (GoatCounter)

GoatCounter (`https://ownchickens.goatcounter.com/count`) is a privacy-friendly, cookie-free counter. Its script tag is in the `<head>` of every page: new pages get it from `tools/layout.py`, and `python3 tools/sync_layout.py` adds it to any page missing it. `analytics.provider` in `site-config.js` stays empty so visits are not counted twice; the loader is only for swapping to another provider. `privacy.html` describes GoatCounter and MailerLite.

### Corrections

The "Report a correction" links on the law pages open a prefilled GitHub issue. Optionally set `corrections.email` to a monitored inbox to offer email as well.

## ZIP lookup (home page)

`zip-lookup.js` runs fully in the browser with two free, no-key, CORS-enabled APIs: `https://api.zippopotam.us/us/{zip}` (city and state) and `https://geo.fcc.gov/api/census/area` (county, optional). It shows verified records from `data/local-laws.json` first (matched by exact ZIP or by city name + state). If there is no verified record it says so plainly and lists Municode / American Legal searches, city and county website searches, the state agriculture program and extension office (the `STATES` table in `zip-lookup.js` covering all 50 US states, URLs checked 2026-10-25), a note about unincorporated areas, and a "suggest this city" link. If the ZIP API is down it falls back to exact-ZIP matches in the local data. It never generates rules. Lookups are counted in GoatCounter as the `zip-lookup` event.

To add a state, add an entry to `STATES` with official URLs only.

## Local law data

`data/local-laws.json` holds one record per city. **Only add rules verified on official sources** (the city's site, ordinance, application or fact sheet). Each record needs source links and a `sourceLastChecked` date. Current coverage: 37 verified cities across 7 Midwest states (24 Wisconsin cities plus 13 major cities across MN, IL, IA, MI, IN and OH), plus state-level agriculture and extension links for all 50 US states.

After editing the JSON:

```sh
python3 tools/build_city_pages.py   # laws/<id>.html + the city cards on laws.html
python3 tools/sync_layout.py && python3 tools/build_sitemap.py && python3 tools/check_site.py
```

Re-check sources and update the dates at least yearly. Fees often change each January.

## Editing workflow

1. Edit page content directly in the HTML.
2. To change the nav (Guides, Laws, Breeds, Costs + "Check your ZIP"), the slim footer or guide sub-nav, edit `tools/layout.py` and run `python3 tools/sync_layout.py`. This rewrites the header and footer on every page and makes sure `site-config.js` loads first.
3. After adding or removing pages, run `python3 tools/build_sitemap.py`. Pages marked `noindex` are skipped.
4. Before pushing, run `python3 tools/check_site.py`. It checks tag balance, duplicate ids, internal links and anchors, image alt text, meta/OG/canonical tags, JSON-LD, FAQPage content, data files, law records and sitemap coverage.

New pages should copy an existing page's head: a unique title and description, canonical, OG/Twitter tags, a breadcrumb plus Article/BlogPosting JSON-LD, and a FAQPage only when the FAQ is visible on the page.

Content rules: don't invent statistics, prices or product test results. Any cost must be a conservative range labeled "typical range, check local prices". Health advice should point to a vet who treats poultry.
